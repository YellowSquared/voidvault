Storage & Sync Settings

100% Offline & Private

Vault ciphertext is stored strictly in local browser storage. Zero network requests, zero telemetry, and zero remote server required. Decryption operates entirely in volatile memory with your physical FIDO2 key.

VoidVault uses a blind relay server. The server stores only blinded ciphertext and never receives passwords, salts, or encryption keys.
